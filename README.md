# Calculadora Web

Este proyecto es una calculadora web desarrollada con **HTML, CSS y JavaScript**.  
Permite realizar las cuatro operaciones básicas: **suma, resta, multiplicación y división**.

## 🚀 Características
- Interfaz sencilla y fácil de usar.
- Validación de entradas (solo números).
- Prevención de división por cero.
- Diseño responsivo con estilos CSS.

## 📂 Archivos del proyecto
- `index.html` : estructura principal en HTML.
- `style.css` : estilos visuales personalizados.
- `script` dentro de HTML : funcionalidad en JavaScript.
